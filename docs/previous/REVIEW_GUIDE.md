# Questions for colleagues

1. Is the dependency order natural? Which prerequisites are missing or late?
2. Which alternative proofs should remain, and which should become references?
3. Are irreducibility, aperiodicity, strict positivity, equal letter weights,
   and rank hypotheses specified precisely?
4. Which operator notation should be retained? The old/new swap is flagged.
5. Are common-letter, independent-particle, and opposite-letter dynamics
   clearly distinguished?
6. Where are more examples, exercises, or counterexamples needed?
7. Should Lie methods, graph lifts, and permanent chains remain main chapters?
8. Is stating the road coloring theorem without its full proof appropriate?

Please separate mathematical corrections, organizational suggestions, and
presentation comments. Identify comments by chapter, section title, and
statement label where possible. Appendix D is deliberately historical;
its useful arguments and uncompleted strategies need particular scrutiny.
